# Aurora Project 3.2.0 Beta 3 — Vela Nocturne

**Vela Nocturne** apresenta uma nova experiência de configuração do Aurora Studio. O onboarding ganhou navegação lateral, uma prévia viva do perfil que acompanha as escolhas e cartões reorganizados para usar o espaço com clareza. O tema escuro permanece consistente, independentemente da aparência configurada no desktop.

As páginas agora deslizam lateralmente, e os carrosséis de aparência e sons usam movimentos mais suaves, com um desfoque sutil durante a troca. O fluxo continua mostrando apenas as etapas necessárias: o treinamento do nome de ativação aparece quando a palavra escolhida precisa dele.

A versão atualiza as demonstrações animadas renderizadas pelos próprios componentes da aplicação. O README, o site do GitHub Pages e a descrição da release mostram os novos GIFs.
