# Aurora Android Companion — descontinuado

**Anúncio — 23 de outubro de 2026:** o cliente Android foi descontinuado. Não há suporte, novas builds ou releases Android. O trabalho ativo volta ao cliente desktop Linux.

O código-fonte e os tags permanecem neste repositório como registro histórico. As páginas de release e os APKs Android foram retirados. O motivo da decisão e o registro de testes e validações estão em [ARCHIVE.md](ARCHIVE.md).
